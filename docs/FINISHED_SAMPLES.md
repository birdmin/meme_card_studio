|---|---|---|---|

보이는 것을 확인했습니다 (T03-C26, 아래 검사 로그 참고).

## 사용 권한 (T03-C27)

이 3개 이미지의 배경은 전부 이 프로젝트의 테스트용으로 직접 생성한 단색/그라디언트
이미지입니다 (`docs/scripts/gen_images.js`로 코드에서 직접 생성, 실사진이나 타인의
저작물이 아님). 폰트는 Google Fonts의 Pretendard·Fraunces(오픈소스 라이선스, 상업적
사용 가능)를 사용했습니다.

> **본인 제작**: 배경 이미지·합성 결과물 전부 본인(제작 도구 개발자)이 직접 생성함.
> 외부 사진/일러스트를 가져다 쓴 부분 없음.

## 위치 정보 메타데이터 확인 (T03-C28)

Python Pillow로 3개 파일의 EXIF를 직접 읽어 확인했습니다.

```
완성본1-1x1-런치.png     -> EXIF 항목 수: 0 | info keys: []
완성본2-4x5-가을카드.png -> EXIF 항목 수: 0 | info keys: []
완성본3-16x9-주말.png    -> EXIF 항목 수: 0 | info keys: []
```

**0건 확인.** 이 도구는 업로드된 원본 이미지의 EXIF를 읽지 않고, 항상 `<canvas>`에
다시 그려서 내보내기 때문에 GPS를 포함한 모든 EXIF가 애초에 결과물에 남지 않습니다
(카드 1 설계 당시부터 의도한 동작).

## 개인정보·비밀값 0건 확인 (T03-C29, T03-C30)

저장소 전체를 다음 패턴으로 검사했습니다.

```bash
grep -rniE "api[_-]?key|secret|password|token|access[_-]?key|private[_-]?key" .
grep -rniE "[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}|01[0-9]-?[0-9]{3,4}-?[0-9]{4}" .
```

두 검사 모두 **일치 항목 0건**. 이 프로젝트는 로그인·서버·API 호출이 전혀 없는
정적 페이지라 애초에 비밀값을 다룰 지점이 없습니다(로컬 `localStorage`에도
템플릿 데이터 외 개인정보를 저장하지 않음).
