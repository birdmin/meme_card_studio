# 카드 4 — 템플릿 CRUD 검증 결과

Playwright로 `docs/scripts/check_templates.js`를 실행해 실제 브라우저에서
저장/불러오기/수정/삭제/새로고침 유지를 확인했습니다.

## 저장 정책
- 최대 **10개**까지 저장. 11번째를 저장하면 **가장 먼저 저장된 템플릿이 자동으로 삭제**됩니다(FIFO).
- 안내 문구를 저장 버튼 아래 항상 노출: "최근 10개의 템플릿만 저장 가능합니다."
- 모든 수정·삭제·덮어쓰기는 배열 순서(index)가 아니라 **템플릿 고유 id**로 대상을 찾습니다.
  (막히는 지점 힌트에 나온 "안정된 ID 사용 → 현재 배열 위치 사용 금지"를 그대로 반영)

## 검사 결과

| 항목 | 시나리오 | 결과 |
|---|---|---|
| T03-C17 생성 3개 이상 | 템플릿을 11개 연속 저장 시도 | 정상 생성, 10개 제한도 함께 확인 |
| 10개 초과 자동 삭제 | 11번째 저장 시 | `템플릿1`이 삭제되고 `템플릿2~11` 10개만 남음 (localStorage 실측 길이 10) |
| 모달 렌더링 | 템플릿 목록 보기 클릭 | 카드 10개 정상 렌더 |
| T03-C19 수정(이름 변경) | 카드의 이름 입력칸 수정 | localStorage에 즉시 반영됨 |
| T03-C19 수정(내용 덮어쓰기) | "현재 화면으로 수정" 클릭 | 확인창 승인 후 해당 템플릿의 이미지/문구/블러가 현재 화면 기준으로 교체됨 |
| T03-C18 불러오기 | 다른 문구를 입력해둔 상태에서 "불러오기" 클릭 | 편집기 문구가 저장된 값(`문구 11`)으로 정확히 복원됨 (입력해둔 임시문구는 버려짐) |

| 크래시 여부 | 전체 시나리오 | JS 에러(pageerror) 0건 |
